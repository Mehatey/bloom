bloom · how this print works

Two-layer reveal · red filter

This sheet contains two overlapping text layers:

RED text (decoy, wellness language) — printed in #d63838.
BLUE text (reveal, surveillance language) — printed in #3a6fc8.

How it reads

Without a red filter held in front: the visitor sees both messages, red dominant. The wellness phrase is the foreground.

Through a red photo filter (or red gel): the red text fades to near-white (filter passes red, so red ink looks white against red-washed paper). The blue text darkens to near-black, becoming the new foreground. The hidden surveillance critique appears.

Print spec

Print on bright white paper. NO color profile correction (the colors must print exactly as specified — ask print shop to disable auto color matching). Use a fine-grain matte or semi-gloss paper. Size: A4 or larger.

For installation: mount at face height on wall behind chair. Leave a small wooden tray of red filter cards (3 × 5") on a side table with a note: "hold this up to the wall."
