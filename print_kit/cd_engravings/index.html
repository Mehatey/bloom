To convert SVG → Illustrator .ai

Open any .svg in Illustrator (File → Open). It loads as fully editable vectors. Then File → Save As → choose Illustrator (.ai) format. No conversion tool needed — Illustrator reads SVG natively.

Before laser engraving

Open in Illustrator → select all <text> → Type → Create Outlines. This converts the italic word + BLOOM text + N° label into vector paths so the laser doesn't need the font installed.

Print or laser?

Laser on CD: only the round center (within the dashed CD boundary) engraves. The 4 corner labels would be off the disc. Print on paper / shiny paper / mylar: the full square prints — everything visible including corners.
